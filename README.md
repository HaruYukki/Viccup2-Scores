# Viccup2 计分中心

打开 `index.html`，选择「黑流树海」或「无终奇语」进入对应计分板。封面使用相同的 7:5 窗口，等比居中裁切；桌面并排显示，手机纵向排列。

## 文件结构

- `index.html`：首页。
- `assets/`：用户提供的两张主题封面。
- `黑流树海/index.html`：黑流树海计分台。
- `无终奇语/index.html`：无终奇语计分板。
- 各主题的 `README.md`：对应规则及维护说明。

## 本局记录

两个计分板使用独立的浏览器本地存储，修改次数、勾选项目和点击 + 时自动保存。返回首页或刷新后恢复本局；「清空本局」只清空当前主题。数据不会上传到 GitHub，也不会在设备之间同步。浏览器清理网站数据后记录会消失。浏览器禁用存储时，计分仍然可用，但会显示无法保存的提示。

直接以文件方式打开时，存储行为取决于浏览器；通过 GitHub Pages 使用更稳定。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch，选择 `main` 和 `/ (root)` 后保存。首页和两个主题使用相对路径，可以部署在仓库子路径下。仓库根目录保留 `.nojekyll`，无需安装依赖或构建。

分数显示统一四舍五入到两位小数，中间计算保留精度。
