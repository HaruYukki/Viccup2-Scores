# 黑流树海 · 探索计分台

无需安装依赖的单文件计分应用。打开 index.html 即可使用；也可以通过 GitHub Pages 发布。

## 计分规则

个人得分 =（游戏内结算分 − 零件数量 × 5）÷ 2 + 特殊得分。

- 作战项目每局最多生效一次。
- 五层结局合并「痛苦将息 / 混沌源阶理论」，300 分。
- 五层结局和畸症勾选「未击败 BOSS」时仅计对应分数的 25%。
- 非作战项目支持重复计数，输入框旁的 + 按钮每次增加 1。
- 耗时少于 150 分钟加 150 分；150～180 分钟（含边界）不加减分；超过 180 分钟按超出分钟数 × 10 扣分。
- 耗时留空暂按 0 分处理，支持小数分钟。

## 使用和维护

页面、样式和逻辑均位于 index.html，无需构建步骤。

- 修改 combat 数组可以调整作战项目的名称和分值。
- 修改 repeats 数组可以调整非作战项目的名称和分值。
- calculate() 负责计分和结果展示。
- 当前输入只保留在页面中，刷新或关闭页面后不会保存。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支的 / (root) 目录。保存后等待部署完成。网页入口位于 /黑流树海/。之后修改并提交本目录的 index.html，站点会随之更新。

## 核对示例

结算分 1000、零件数量 20 时，基础分为 450。
五层结局和畸症均勾选未击败 BOSS 时，作战加分为 75 + 125 = 200。
小黑人计数 2、果 / 轮扣分计数 1 时，非作战加分为 240 − 80 = 160。
不计时间分时，总分为 810。
