# 无终奇语计分板

打开 `index.html` 即可离线使用，无需安装依赖。页面不保存输入，刷新前请自行记录结果。

## 计分规则

个人得分 =（游戏内结算分 + 特殊得分）× 挑战难度系数。

- N16：×1；N18：×1.4，两项互斥，默认 N16。
- 紧急作战：各项目勾选后生效一次，混乱状态额外加 20 分。
- BOSS 作战：朝谒 150 分、授法 300 分、不容拒绝小蛋 300 分 / 超大蛋 800 分。混乱状态将选定项目的分数乘 1.5。
- 授法未击败 BOSS 时，仅获得该项特殊得分的 25%；同时混乱时为 300 × 1.5 × 25% = 112.5 分。
- 携带滚动先祖：加 500 分，不乘混乱状态的 1.5；仍参与最终挑战难度乘算。
- 4 / 5 / 6 星临时招募分别加 10 / 20 / 50 分每次；鸭狗熊鼠加 50 分每次，支持输入次数和点击 + 增加次数。
- 不计算零件或时间得分。

## 维护

页面、样式和计算逻辑均在 `index.html` 中。`emergency`、`bosses`、`repeats` 数组定义项目；`calculate()` 负责组合计分。取消主项目会清除并禁用其附加勾选项。

如果仓库已启用 GitHub Pages，页面路径为 `/Viccup2-Scores/无终奇语/`。
